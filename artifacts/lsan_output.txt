=== LeakSanitizer (LSan) ===

Статус: ⚠️ НЕ ЗАПУЩЕН

Причина: LeakSanitizer не поддерживается на macOS ARM64.

Попытка запуска:
RUSTFLAGS="-Zsanitizer=leak" cargo +nightly test --tests

Результат:
error: leak sanitizer is not supported for this target

Документация: https://doc.rust-lang.org/rustc/sanitizers.html

Альтернатива: Использован Valgrind через Docker для проверки утечек.

Результат Valgrind (artifacts/valgrind_output.txt):
==1== All heap blocks were freed -- no leaks are possible

Вывод: Проверка утечек выполнена через Valgrind. Утечек не обнаружено.

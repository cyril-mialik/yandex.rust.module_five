=== AddressSanitizer (ASan) ===

Статус: ⚠️ НЕ ЗАПУЩЕН

Причина: Известная проблема ASan на macOS ARM64 - "Interceptors are not working".

Попытка запуска с правильной переменной:
export DYLD_INSERT_LIBRARIES=$(find ~/.rustup -name "librustc-nightly_rt.asan.dylib" | head -1)
RUSTFLAGS="-Zsanitizer=address" cargo +nightly test --tests

Результат:
==5792==ERROR: Interceptors are not working.
This may be because AddressSanitizer is loaded too late (e.g. via dlopen).
Please launch the executable with:
DYLD_INSERT_LIBRARIES=/Users/.../librustc-nightly_rt.asan.dylib

Попытка выполнена с правильной переменной, но ошибка сохраняется.

Причина: Известный баг на macOS ARM64 (Apple Silicon).
Документация: https://github.com/rust-lang/rust/issues/120000

Альтернатива: Использован Valgrind через Docker для проверки памяти.

Результат Valgrind (artifacts/valgrind_output.txt):
==1== ERROR SUMMARY: 0 errors from 0 contexts
==1== All heap blocks were freed -- no leaks are possible

Вывод: Проверка памяти выполнена через Valgrind. Ошибок и утечек не обнаружено.
